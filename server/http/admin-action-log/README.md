# HTTP za dnevnik radnji administratora i operatera

`GET /api/v1/institution/admin-actions` (SRV-ADMIN-1, NF-7 OA-3) daje potvrđenom administratoru ustanove dnevnik radnji administratora i operatera te ustanove, samo za čitanje, najnovije prve, najviše 500 (`truncated` kaže da ih ima još). Unos ima vrijeme, ulogu, vrstu radnje (uloga potvrđena ili povučena, pravilo objavljeno, prag promijenjen, zadržavanje postavljeno ili skinuto, izvoz zatražen ili odobren, uvoz popisa studenata potvrđen s id-em kolegija i brojevima upisanih, već upisanih i preskočenih u `rosterImport`), ulogu na koju se radnja odnosi i ishod, bez osoba, studenata, radova i slučajeva. Tko ga smije čitati odlučuje baza (migracije `20261215100100_admin_action_log.sql` i `20261217130000_admin_action_log_roster_import.sql`); drugi dobivaju 403. Odgovor nosi `Cache-Control: no-store`.
