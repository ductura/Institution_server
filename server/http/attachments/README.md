# HTTP rute privitaka

- `POST /api/v1/student/assignments/{assignmentId}/attachments` prima JSON s `imageBase64` (PNG ili JPEG do 5 MiB). Vraća metapodatke privitka i `created`.
- `GET /api/v1/work-attachments/{attachmentId}` vraća metapodatke i `imageBase64`. Vlasnik rada i čitatelji kojima postojeći odnos daje pristup mogu čitati sliku.

`server/server.ts` montira obje rute preko `createAttachmentRoutesFor`. Pozivatelj iz odgovora za prijenos uzima `attachmentId` i `attachmentSha256` za blok slike v4. HTTP test pokreće stvarni router i datotečnu pohranu s probnim RPC odgovorima.

Servis prepoznaje PNG i JPEG iz strukture datoteke, bilježi prirodne dimenzije i SHA-256 te čuva bajtove bez metapodataka (DAN-1121). `metadata.ts` iz JPEG-a uklanja segmente APP1 (Exif, XMP), APP13 i COM te sve iza prvog EOI, a iz PNG-a chunkove eXIf, tEXt, zTXt, iTXt i tIME; ostali segmenti i slikovni podaci kopiraju se bajt po bajt, bez ponovnog kodiranja. Ako prvi Exif APP1 prije skeniranja ima oznaku Orientation (0x0112, SHORT) s vrijednošću 2–8, na njegovo mjesto upisuje se novi, minimalni APP1 Exif s jednim IFD0 i samo tom oznakom, da se uspravne fotografije s mobitela ne prikazuju zakrenute; vrijednost 1, nedostajuća ili neispravna oznaka znači da APP1 nema. PNG se ne mijenja. Zadržani dijelovi bilježe se kao spojeni uzastopni rasponi, pa memorija raste s brojem prekida, a ne s brojem segmenata. SHA-256, `byteSize` i odgovor odnose se na spremljene bajtove. Ako se struktura ne može obići ili se dimenzije promijene, prijenos se odbija kao `invalid_input`. Već spremljeni privici se ne mijenjaju. RPC-ovi SRV-10B utvrđuju ovlasti, ograničenja i ponovljeni prijenos. Pogreška pohrane prekida transakciju. Pri čitanju servis provjerava duljinu i SHA-256 bajtova.

Lokalni adapter koristi `.local/attachments` kada je `NODE_ENV` `development` ili `test`. Za druga okruženja treba postaviti `DUCTURA_ATTACHMENT_DIRECTORY` na apsolutnu putanju privatnog trajnog direktorija. Prekid između objave datoteke i potvrde transakcije može ostaviti datoteku bez retka u bazi.
