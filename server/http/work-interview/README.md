# HTTP rute za pripremu razgovora

GET s valjanom sesijom dohvaća pripremu rada: pitanja, poziv, objašnjenja, termin i datum održanog razgovora. Nastavnik ili mentor rada dodaje i briše pitanja, šalje poziv, postavlja termin i bilježi da je razgovor održan; student vlasnik nakon poziva upisuje objašnjenja i bira termin konzultacije. Baza provjerava odnos korisnika prema radu. Nema polja za ishod, ocjenu, sankciju ni sumnju.
