# self-note-sealed

HTTP rub šifrirane „Poruke sebi” (`work.sealed-self-note.*`) i omotanog ključa poruka (`profile.self-note-key.*`), SRV-NF6-SIFRA, varijanta B2 (`docs/contracts/self-note-sealed-v1.md`). Samo rub: kolačić sesije, identifikator rada, vrsta medija, ograničeno tijelo i njegov oblik, zatim `server/database/self-note-sealed`. Tko smije odlučuje baza. Tijelo se nikad ne zapisuje u log ni u izvještaj o grešci.
