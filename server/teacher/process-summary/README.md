# Sažetak procesa (N-10)

Nastavnik zadužen za rad i student vlasnik dobivaju isti sažetak iz postojećeg izvora koji zapisuje nastavnički pristup. Za predani rad izvor čitanje ograničava na predanu reviziju.

Aktivno vrijeme uređivanja je zbroj raspona sesija u cijelim minutama umanjen za praznine u zapisu. Sažetak nosi lijepljenja iznad praga i praznine u zapisu. Uvozi i prijenosi iz pomoćnika navode se po vrsti i vremenskom rasponu odsječka kad ih evidencija sadrži.
