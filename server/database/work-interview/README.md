# Priprema za razgovor

Sedam RPC-a glavne baze čitaju pripremu rada, dodaju i brišu pitanja, šalju poziv, bilježe termin i održan razgovor te spremaju studentova objašnjenja. Identitet dolazi iz sesije vezane uz transakciju. Adapter vrijeme pretvara u UTC za HTTP odgovor. Nema polja za ishod, ocjenu, sankciju ni sumnju.
