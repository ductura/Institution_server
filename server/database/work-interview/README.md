# Priprema za razgovor

Osam RPC-a glavne baze čitaju pripremu rada, dodaju i brišu pitanja, šalju poziv, bilježe termin i održan razgovor te spremaju studentova objašnjenja i priloge bilješke (tekst ili PDF do 1 MiB, nakon poziva, dok razgovor nije održan). Identitet dolazi iz sesije vezane uz transakciju. Adapter vrijeme pretvara u UTC za HTTP odgovor. Nema polja za ishod, ocjenu, sankciju ni sumnju.
