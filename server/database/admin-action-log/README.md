# Dnevnik radnji administratora i operatera

Jedan poziv `app.admin_action_log()` preko `withActor` (SRV-ADMIN-1, NF-7 OA-3; migracija `20261215100100_admin_action_log.sql`). Čita ga samo potvrđeni administrator ustanove (`ZD403` inače, `ZD401` bez sesije). Redak ima vrijeme, ulogu koja je radila, vrstu radnje, ulogu na koju se radnja odnosi i ishod, a nikad osobu, studenta, rad, slučaj ni zahtjev. Zapisi dolaze iz postojećih tragova koji se samo dopisuju, pa se ne mijenjaju ni ne brišu (pgTAP `db/main/tests/233-admin-action-log.sql`). Čitač ponovno provjerava skupove vrijednosti i da samo radnja nad ulogom nosi ulogu. Od SRV-ADMIN-2B (migracija `20261217130000_admin_action_log_roster_import.sql`, pgTAP `240-admin-action-log-roster-import.sql`) potvrda uvoza popisa studenata je vrsta radnje `roster_import_confirmed`; redak nosi id kolegija i tri broja (upisani, već upisani, preskočeni), a čitač odbija redak u kojem ih ima druga radnja ili im neki nedostaje.
