# Predložak rada ustanove (SRV-V17-TEMPLATE-ADMIN)

`createWorkTemplate` je port nad `app.read_work_template` i `app.publish_work_template`: verzije predloška jedne vrste rada (naslovna, kostur odjeljaka, stil navođenja). Verzija se samo dodaje. Tko smije, odlučuje baza (administrator ustanove); ZD401, ZD403, ZD409 i ZD422 se ne hvataju ovdje.
