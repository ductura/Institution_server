# Probni prolaz čuvanja

Jedan poziv `app.retention_candidates()` preko `withActor`. Funkcija ne prima ustanovu: uzima je iz sesije (pgTAP `033-institution-key.sql`, U1) (migracija `20261210130400_retention_dry_run.sql`, SRV-1304). Funkcija samo čita (`STABLE`, pgTAP `db/main/tests/182-retention-dry-run.sql`) i po klasi vraća broj redaka koje bi brisanje uzelo; ništa ne briše. `ZD401` čitač vraća kao `unauthenticated`, `ZD403` (nije administrator ustanove iz sesije) kao `forbidden`. Brojeve slaže u izvještaj `retentionReport` iz `server/domain/retention`, koji odbija nepoznatu klasu i neispravan broj.
