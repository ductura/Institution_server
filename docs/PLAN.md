## 1. Svrha i granica

**Svrha.** Jedini server i jedini API (`/api/v1`) za web i desktop. Posjeduje prijavu AAI@EduHr (D-09), FIDO2 za mrežnog inženjera, ovlasti pet vrsta računa, sve baze (glavna, zapisi, pravni tekstovi), zapise, metriku, backup, manifest za preuzimanje i testni server. Drži **ugovor API-ja kao izvor koda** (§5) i objavljuje pakete `@ductura/contracts` i `@ductura/test-fakes`.

**Granica (nikad ne ulazi):**

- stranice, React, CSS, editor, Dexie, bilo što ovisno o pregledniku;
- Next.js i server actions (zadaci §2: čisti Node.js HTTP API);
- drugi način prijave studenata osim AAI@EduHr; lažni OIDC izvan lokalnog rada i CI-ja;
- tajne, ključevi, stvarne adrese i osobni podaci; primjena migracija na produkciju iz agenta;
- pisanje klijenta izravno u tablice evidencije, predaje i revizijskog traga (samo RPC).

## 2. Zatečeno stanje (kostur, 14. 11.)

- Repozitorij `ductura/Institution_server` na početku: jedan commit. CI zelen.

## 3. Sadržaj i modularni monolit (odluka B3)

```
server/server.ts            -> dist/server.js (jedini ulaz, S-1B-a)
server/<područje>/          index.ts (javno sučelje), routes.ts, schemas.ts, service.ts, *.test.ts, README.md (hr)
server/contracts/           ugovor: sheme svih ruta, inventar, OpenAPI, greške, „tko smije”
locales/  db/main|logs|legal/  openapi/v1.json  contracts/vectors/
packages/contracts/         @ductura/contracts (generirano iz server/contracts)
packages/test-fakes/        @ductura/test-fakes (odluka B4)
tests/functional/, tests/lint/, scripts/ (TS), infra/postgres/, docs/, .github/ (poziva ductura/.github)
```

**Područja** (zadaci §2 i val 6): `http`, `traffic`, `session`, `external/srce-auth`, `external/storage`, `external/keys`, `external/email`, `database`, `config`, `log`, `metrics`, `roles`, `settings`, `legal`, `backup`, `deletion`, `downloads`, `contracts`, `domain`, `test-server`, `profile`, `support`, `institution`, `teacher`, `evidence`, `submission`, `collaboration`, `projection`, `privacy`.

**Pravilo granica (provjerava CI, S-1A-b):**

1. Područje drugom području nudi samo ono što izvozi njegov `index.ts`; dubok uvoz (`server/x/service.ts` iz `server/y`) ruši lint.
2. `server/domain` ne uvozi ništa; `server/contracts` uvozi samo knjižnicu shema.
3. `routes.ts` uvozi samo `contracts`, `http` i vlastiti `service.ts`, bez logike.
4. Samo `server/database` uvozi `pg` i PGlite; nitko ne uvozi `react`, `next/*` ni `.tsx`.
5. Kružni uvozi između područja zabranjeni.
   Alat: ESLint (S-1A-b već ga koristi), PRIJEDLOG `eslint-plugin-boundaries`; dependency-cruiser samo ako ESLint ne pokrije kružne i dinamičke uvoze. Svako pravilo ima fixture koji mora pasti. Pravilo se uvodi uz S-1A-a i S-1A-b, a vrijedi za svaki kasniji zadatak servera.

## 7. CI i gate

- **Poslovi** (pozivaju reusable workflowe iz `ductura/.github`): `lint` (s granicama), `format`, `typecheck`, `test-helpers`, `test-functional`, `pgtap-main`, `pgtap-logs`, `pgtap-legal`, `contracts` (generirano = commitano, vektori, lomljenje), `secret-scan`, `dependency-review`, `publish` (na oznaku), `ci-ok`.
- **Obvezno na `main`:** `ci-ok` i statusi gatea. Akcije prikvačene na SHA.
- **Gate:** risk floor po putanjama (najmanje `critical` za `server/server.ts`, `server/http/**`, `server/session/**`, `server/external/srce-auth/**`, `server/contracts/**`, migracije, pgTAP, `.github/**`); dvije aplikacije za `critical`; Mergify; botovi. Promjena pravila gatea samo kroz U11 i vlasnikovu potvrdu.
- **Izdanja:** `@ductura/contracts` i `@ductura/test-fakes` na GitHub Packages (U10). Napomena: npm registar GitHub Packages traži token i za javne pakete; u CI-ju istog organizacijskog računa dovoljan je `GITHUB_TOKEN` s `packages: read` uz dodijeljen pristup repou; lokalno treba osobni token s `read:packages`. Zato je svaka verzija i `.tgz` na javnom GitHub Releaseu oznake (`contracts-vX.Y.Z`, `test-fakes-vX.Y.Z`), koji se instalira bez tokena (DAN-966). Kasnije Docker slika testnog servera (S-1H.7) samo kao izdanje.
- **Vlasničke radnje:** V-0 … V-7; potvrda U11.
